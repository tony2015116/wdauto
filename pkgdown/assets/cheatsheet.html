Drivers match the installed browser

get_cd(dest_dir, browser = "chrome", zip = NULL)

Downloads the ChromeDriver or EdgeDriver for the installed browser into dest_dir and returns its path invisibly.

  • A cached driver of the same milestone is reused without network access
  • The newest three driver versions are kept
  • zip = "chromedriver-win64.zip" — install an archive downloaded elsewhere
get_ss(dest_dir, jar = NULL)

Selenium Server 3.141.59 for backend = "selenium"; falls back to GitHub Releases. jar = installs a local JAR.

get_cd(driver_dir)
get_cd(driver_dir, browser = "edge")
# Selenium backend only
get_ss(driver_dir)

Service start or reuse

auto_cs(dest_dir, autostart = TRUE, browser = "chrome", backend = "selenium", restart = "if_idle")

Starts the managed service, or reuses the running one, and waits until it accepts connections.

ArgumentEffect
backendChrome only: "chromedriver" (no Java) or "selenium"
autostart = FALSEstart once, without the login startup entry
restart = "never"error instead of restarting after a browser update
auto_cs(driver_dir, backend = "chromedriver")
auto_cs(driver_dir, browser = "edge")

Mirrors and offline slow or blocked networks

Downloads try the mirror first and always fall back to the official servers.

options(wdauto.mirror = "npmmirror")
# or as an environment variable
Sys.setenv(WDAUTO_MIRROR = "npmmirror")
# no network at all: files from
# another computer
get_cd(driver_dir, zip = "D:/driver.zip")
get_ss(driver_dir, jar = "D:/selenium.jar")

Other mirrors: a named vector of URL prefixes and their replacements, see ?get_cd.

The mirror option in effect when auto_cs() writes the startup entry is reused at login.

Login and updates runs on its own

  • Startup entry: wdauto_chrome.vbs / wdauto_edge.vbs in the current user's Startup folder, hidden, Unicode paths
  • At login the driver is resolved again; the start is retried for about two minutes while the network comes up
  • After a browser update, the next auto_cs() restarts the service with a matching driver if no session is open
  • Entries written by wdauto 0.1.x (.bat) are replaced

Stop and troubleshoot

reset_cs(browser = "chrome")

Stops the managed service and removes its startup entry, even when the process record is damaged.
