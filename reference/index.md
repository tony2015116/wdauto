# Package index

## Drivers and servers

Download the WebDriver that matches the installed browser, and the
Selenium Server used by the default Chrome backend.

- [`get_cd()`](https://tony2015116.github.io/wdauto/reference/get_cd.md)
  : Download a browser WebDriver
- [`get_ss()`](https://tony2015116.github.io/wdauto/reference/get_ss.md)
  : Download Selenium Server

## Service

Start or reuse the managed local service, keep it running at login, and
stop it again.

- [`auto_cs()`](https://tony2015116.github.io/wdauto/reference/auto_cs.md)
  : Start a local WebDriver service
- [`reset_cs()`](https://tony2015116.github.io/wdauto/reference/reset_cs.md)
  : Stop the managed browser driver and remove its login startup entry
